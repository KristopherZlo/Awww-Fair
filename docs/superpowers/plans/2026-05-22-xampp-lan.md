# XAMPP LAN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing XAMPP checkout serve Trend Market across the local network through Apache, Node API, and MariaDB.

**Architecture:** Apache is the LAN-facing server and serves the built app from `/trendmarket/`. Apache proxies root `/api` requests to a local Node process, while Node uses MariaDB defaults from XAMPP or `.env.xampp`.

**Tech Stack:** React, Vite, Node, TypeScript, MariaDB, Apache httpd, XAMPP.
